Schedule rows

Newest date wins

The display uses the row with the latest date that is on or before today. Most of the time you only need one row and simply edit it.

Advanced: schedule a future change

Add a second row that takes effect from a chosen date (e.g. the first day of Ramadan). Until then the current row stays in effect.

The new row starts as a copy of the schedule you’re editing; edit it afterwards.
